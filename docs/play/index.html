Castle Remembers — native Atari Jaguar (68000 assembly)

This is the real Jaguar program (gate7_castle.cof) running in a Jaguar emulator in your browser. Click the game, then play.

Controls: ←/→ walk · ↑ jump / climb up · ↓ climb down / act · Z act (open door, pull lever, shove guard). Click the game first.
Reach the exit on floor 5. The castle remembers how you played and rebuilds itself against you.

Source, build and tests on GitHub · emulator: EmulatorJS with the Virtual Jaguar core (GPL-3.0).
